// PATTERN: facade
  - singleton: `core/Store` keeps one shared market list for all users.
  - factory method: `core/Maker.make` creates stock/crypto items from simple
  inputs.
  - composite: `model/Group` and `model/Holding` share `value()` for totals.
  - decorator: `trade/PenaltyWrap` adds the 5% day-hold fee on top of
  `BaseCost`.
  - command: `trade/BuyAct` and `trade/SellAct` run trades as objects.
  - facade: `core/Hub` exposes register/login/search/buy/sell/watch/tick.
  - template method: `trade/Steps.execute` fixes the trade flow and uses hooks.
  - strategy: `trade/PlanDay`, `trade/PlanLong`, `trade/PlanAuto` switch
  behavior.

  How It Functions

  - Market + items: Store holds all items (Stock subclasses like AmazonStock and
    BasicItem). Maker builds items for the market.
  - Accounts: Hub.register/login manage User objects. Each User has cash,
    portfolio (Group of Holding), history, watchlist, and a Plan.
  - Trading flow: Main calls Gate.buy/sell, which forwards to Hub. Hub delegates
    to BuyAct/SellAct (command), each running Steps (template method).
  - Trade rules: Hub.canTrade enforces stock hours (Mon–Fri, 09–18) and always-
    on crypto. When blocked, it prints closed.
  - Plans: PlanDay, PlanLong, PlanAuto are strategies applied per user. PlanAuto
    runs on Hub.tick to auto buy/sell by thresholds.
  - Day-fee: Hub.tick checks day-plan holdings. If a day-plan stock holding
    crosses into next day, PenaltyWrap applies 5% and prints fee.
  - History: Steps.record writes Tx entries (buy/sell, ticker, name, qty, price,
    time).
  - Observers:
      - Old-style: Stock notifies IInvestor subscribers (PrivateInvestor/
        PublicInvestor) on setPrice.
      - Extended: WatchCenter notifies IPriceListener (e.g., Watch) with old/new
        prices on Hub.tick.
  - Main demo: Main wires everything, runs a closed-hours trade (prints closed),
    executes buys/sells, triggers watch prints, and triggers day-fee on next-day
    tick.
